# Smart City Sustainability Evaluator

An interactive **R Shiny decision-support application** for exploring and evaluating Smart City initiatives from a sustainability perspective.

## 🚀 Live Application

👉 [Launch the Smart City Sustainability Evaluator](https://mieyy.shinyapps.io/SmartCityEvaluator/)

## 📌 About the Project

The Smart City Sustainability Evaluator translates research on Smart Cities and sustainability into an interactive decision-support tool.

The application allows users to explore Smart City examples, examine digital technologies and evaluate proposed projects across four sustainability dimensions:

- 🌱 Environmental
- 👥 Social
- 💶 Economic
- 🏛️ Governance

The project demonstrates how digital technologies can support sustainability while recognising that technology alone does not automatically produce sustainable outcomes.

## 🔍 Key Features

- Explore Smart City initiatives in German cities
- Examine different Smart City technologies and applications
- Evaluate proposed Smart City projects
- Compare environmental, social, economic and governance performance
- Generate sustainability scores
- Visualise results using interactive charts
- Identify potential benefits, risks and trade-offs
- Download assessment results

## 🛠️ Technologies Used

- **R**
- **Shiny**
- **bslib**
- **Plotly**
- **DT**
- **HTML/CSS**
- Interactive data visualisation
- Decision-support modelling

## 🎯 Project Purpose

This project was developed to demonstrate how research findings can be translated into a practical and interactive digital tool.

Rather than treating technology as inherently sustainable, the application encourages users to consider its environmental, social, economic and governance impacts together.

## ⚠️ Note

This application is a research-informed demonstration and portfolio project. The sustainability scores are intended for exploration and comparison and should not be interpreted as official assessments of cities or Smart City projects.
